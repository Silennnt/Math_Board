# Math-Board

An interactive, real-time online whiteboard application designed for remote mathematics tutoring. This platform allows tutors and students to collaborate in dedicated virtual rooms.

## Planned Features

- **Real-time Collaboration:** Drawing and synchronization powered by Firebase.
- **Room Management:** Private one-on-one sessions, group sessions, and student-led peer study rooms.
- **Automatic Snapshots:** Generating and saving canvas screenshots to a student dashboard after sessions.
- **Modern UI:** Dark theme aesthetic with cyan and violet accents, matching the main portfolio website.

## Technologies

- React & Vite
- Firebase (Authentication, Realtime Database/Firestore, Storage)
- React Konva / Canvas API
